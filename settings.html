Backup Data

Export the complete application data (users, receipts, audit logs, settings) into a structured JSON backup file.

Restore Data
Restoring will replace all current local data with the contents of the backup file. Always maintain regular backups. Browser data may be lost if browser storage is cleared.
System Information
Important: This GitHub Pages version stores data locally in this browser/device. Data does not sync across devices. For centralized multi-user institutional data storage, a secure backend/database is required (e.g. Firebase, Supabase, Node.js + PostgreSQL/MySQL). The frontend is designed so a backend can be integrated later without a complete redesign.
